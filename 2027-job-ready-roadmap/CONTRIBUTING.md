# Contributing to 2027 Job-Ready Roadmap

Thank you for your interest in contributing to the **2027 Job-Ready Developer Roadmap & Study Platform**! This repository is designed to be a comprehensive, free, open-source learning repository and study platform for software engineers.

---

## 🌟 How You Can Contribute

We welcome contributions in the following areas:
- **Adding High-Quality Free Resources:** Official documentation, free video tutorials, and interactive coding exercises.
- **Improving Study Notes:** Clarifying explanations, fixing typos, and adding practical, real-world examples.
- **Code Examples:** Providing idiomatic, well-commented code snippets in Java, JavaScript/TypeScript, SQL, Docker, Kubernetes, etc.
- **Interview Questions:** Contributing real-world behavioral and technical interview questions with thorough explanations.
- **Bug Fixes in Study Dashboard:** Enhancing the Vanilla JS dashboard, fixing CSS layout issues, or optimizing localStorage synchronization.

---

## 📜 Contribution Guidelines

### 1. Document Consistency
Every topic's `README.md` must follow our standardized 12-section structure:
1. Introduction & Prerequisites
2. Detailed Learning Objectives
3. Beginner-to-Advanced Topic Checklist
4. Free Documentation Resources (Only official docs or verified high-quality platforms)
5. Free Video Courses & Tutorials
6. Important Concepts Explained
7. Practical Code Examples
8. Hands-on Practice Assignments
9. Mini-Projects
10. Interview Questions & Detailed Answers
11. Revision Notes & Key Takeaways
12. Topic Completion Checklist

### 2. No Paid Resources as Mandatory
- Do **not** recommend paid courses or bootcamps as mandatory prerequisites.
- Prioritize official documentation (e.g., MDN, Oracle/OpenJDK, Spring.io, Docker Docs, Kubernetes Docs, Apache Kafka Docs, Redis Docs).

### 3. Website Standards
- The study dashboard located in `website/` is built strictly with **Vanilla HTML5, CSS3, and modern ES6+ JavaScript**.
- **No frontend frameworks** (No React, Angular, Vue, Tailwind CSS, or Node.js server dependencies).
- Keep everything accessible directly via static file hosting or GitHub Pages without build steps.

## 🚀 Submitting a Pull Request

1. **Fork** the repository to your own GitHub account:
   ```bash
   git clone https://github.com/AdarshKumar12345/2027-job-ready-roadmap.git
   ```
2. **Create a branch** for your feature or fix:
   ```bash
   git checkout -b feature/topic-or-fix-name
   ```
3. **Commit your changes** with descriptive commit messages following Conventional Commits:
   ```bash
   git commit -m "docs(core-java): add virtual threads benchmark example"
   ```
4. **Push** to your fork:
   ```bash
   git push origin feature/topic-or-fix-name
   ```
5. **Open a Pull Request** against the `main` branch with a clear description of changes.
