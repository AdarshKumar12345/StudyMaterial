# Operating Systems - Study Topics

1. OS Architecture (Dual-mode, System Calls, Monolithic vs Microkernel)
2. Process Management & IPC (Client-Server communication)
3. Multithreading Models and Pthreads
4. CPU Scheduling Algorithms (FCFS, SJF, Priority, Round Robin, Multilevel Queues)
5. Process Synchronization (Critical Section, Hardware Instructions like CAS)
6. Mutexes, Semaphores, and Classic Sync Problems (Producer-Consumer, Monitors)
7. Deadlocks (Prevention, Avoidance, Banker's Algorithm, Detection)
8. Memory Management (Paging, Segmentation, TLB, Virtual Memory)
9. Page Replacement Algorithms (LRU, FIFO, Optimal)
10. File Systems and I/O Subsystems (Disk Scheduling)
