## 11. Important Developer Commands – Quick Reference

### Git

```bash
git init
git clone <url>
git status
git add .
git commit -m "message"
git switch -c feature
git pull origin main
git push origin main
```

### Linux / Terminal

```bash
pwd
ls -la
cd ..
mkdir project
touch file.txt
grep "error" app.log
find . -name "*.js"
chmod 755 script.sh
ps aux
```

### Package Management

```bash
npm install
npm install package-name
npm uninstall package-name
npm run dev
npm run build
npm run start
```

### Docker

```bash
docker --version
docker pull nginx
docker build -t myapp .
docker run -p 3000:3000 myapp
docker ps
docker logs <container-id>
docker compose up -d
docker compose down
```

### SSH

```bash
ssh-keygen -t ed25519
ssh-add ~/.ssh/id_ed25519
ssh user@server-ip
scp file.txt user@server-ip:/path/
```

## 13. Important Concepts to Master

- **Git:** Tracks source code changes and manages version history.
- **GitHub:** Hosts repositories and enables team collaboration.
- **Linux:** Open-source operating system used extensively in servers and cloud infrastructure.
- **Shell:** Command interpreter for interacting with the operating system.
- **Bash:** Popular Unix shell and scripting language.
- **SSH:** Secure protocol for remote system access.
- **Package Manager:** Installs and manages software dependencies.
- **CI/CD:** Automates testing, building and deployment.
- **Docker:** Packages applications into containers.
- **Environment Variables:** Store configuration outside application source code.
- **Makefile:** Defines repeatable build and automation tasks.
- **Dev Container:** Provides a reproducible development environment.
