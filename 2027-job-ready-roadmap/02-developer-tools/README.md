# 🛠️ Module 02: Developer Tooling & Environments

## Overview
A software engineer's productivity depends on command of the developer terminal, version control systems, and UNIX/Linux runtime environments.

| Subtopic | Focus Areas | Difficulty | Estimated Hours | Path |
