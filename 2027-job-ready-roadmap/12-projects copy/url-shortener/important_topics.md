# URL Shortener (Production Capstone) - Study & Implementation Topics

1. High-Level Architecture & Capacity Estimation (Read/Write Ratio)
2. URL Generation Algorithms (Base62 Encoding, MD5 Hashing, UUIDs)
3. Collision Resolution and Key Generation Service (KGS)
4. Database Selection (RDBMS vs NoSQL/Cassandra for high write throughput)
5. Caching Layer Strategy (Redis/Memcached, Cache Aside, LRU Eviction)
6. Handling Redirection (HTTP 301 vs 302 Redirects)
7. Analytics and Tracking (Click rates, Geolocation, Time-series data)
8. Rate Limiting and Abuse Prevention (Throttling API keys)
9. Data Purging and TTL (Time-To-Live) for expired links
10. System Sharding, Partitioning, and High Availability setups
