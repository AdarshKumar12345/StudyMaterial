# Social Media Platform (Production Capstone) - Study & Implementation Topics

1. News Feed Generation (Push/Fan-out on write vs Pull/Fan-out on read)
2. Graph Data Modeling (Followers, Friends, Connections)
3. Media Storage and Delivery (S3, CloudFront/CDN, Image Optimization)
4. Pagination Strategies (Cursor-based vs Offset-based for infinite scroll)
5. Real-Time Chat & Notifications (WebSockets, Server-Sent Events, Redis Pub/Sub)
6. Full-Text Search and Hashtag Tracking (Elasticsearch)
7. Distributed ID Generation for Posts/Tweets (Snowflake ID)
8. Event-Driven Architecture for Asynchronous Tasks (Kafka/RabbitMQ)
9. Database Sharding Strategies (Sharding by User ID vs Post ID)
10. Algorithmic Feed Ranking and Recommendation Engines
