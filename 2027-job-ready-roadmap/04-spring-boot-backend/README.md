# 🍃 Module 04: Enterprise Backend with Spring Boot 3+

## Overview
Spring Boot 3 (Spring Framework 6, Java 17/21) is the enterprise standard for backend systems. This module covers build tooling, dependency injection, REST APIs, persistence with Hibernate/JPA, security with JWT, caching, search, and messaging.

## Learning Path & Topics
| Subtopic | Focus Areas | Difficulty | Estimated Hours | Path |
|:---|:---|:---:|:---:|:---|
| **Apache Maven** | Lifecycle, POM, BOM, dependency scopes, plugins | Beginner | 6 hrs | [maven/](maven/Maven.md) |
| **Spring Core & IoC** | ApplicationContext, bean scopes, DI, AOP | Intermediate | 14 hrs | [spring-core/](spring-core/SpringCore.md) |
| **Spring Boot 3 REST APIs** | Auto-configuration, validation, ProblemDetail, Actuator | Intermediate | 20 hrs | [spring-boot/](spring-boot/SpringBoot.md) |
| **Hibernate & JPA** | Entities, relationships, N+1, transactions, auditing | Intermediate | 18 hrs | [hibernate/](hibernate/Hibernate.md) |
| **Spring Security 6 & JWT** | SecurityFilterChain, stateless JWT, refresh tokens, RBAC | Advanced | 22 hrs | [spring-security/](spring-security/SpringSecurity.md) |
| **Redis Caching** | Cache-aside, TTL, eviction, distributed locks | Intermediate | 12 hrs | [redis/](redis/Redis.md) |
| **Elasticsearch** | Inverted index, Query DSL, analyzers, Spring Data ES | Advanced | 14 hrs | [elasticsearch/](elasticsearch/Elasticsearch.md) |
| **RabbitMQ** | AMQP, exchanges, queues, DLQ, acknowledgements | Intermediate | 12 hrs | [rabbitmq/](rabbitmq/RabbitMQ.md) |
| **Apache Kafka** | Topics, partitions, consumer groups, offsets, exactly-once | Advanced | 22 hrs | [kafka/](kafka/Kafka.md) |

## Prerequisites
- Core Java (OOP, Collections, Streams), basic SQL, HTTP basics.

## Suggested Order
Maven → Spring Core → Spring Boot → Hibernate/JPA → Spring Security → Redis → RabbitMQ → Kafka → Elasticsearch
