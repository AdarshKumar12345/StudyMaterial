# Low-Level Design (LLD) & OOAD - Study Topics

1. Object-Oriented Principles (Abstraction, Encapsulation, Inheritance, Polymorphism)
2. SOLID Principles (Single Responsibility, Open/Closed, Liskov, Interface Segregation, Dependency Inversion)
3. DRY, KISS, and YAGNI Principles
4. Creational Design Patterns (Singleton, Factory, Builder, Prototype)
5. Structural Design Patterns (Adapter, Decorator, Facade, Proxy)
6. Behavioral Design Patterns (Strategy, Observer, Command, State)
7. UML Diagrams (Class, Sequence, Use Case, Activity, State Diagrams)
8. API Design and Contract Drafting (RESTful best practices, Idempotency)
9. Database Schema Design (Normalization, Denormalization, Entity-Relationship)
10. Concurrency Handling (Locks, Mutexes, Semaphores, Thread Pools)
