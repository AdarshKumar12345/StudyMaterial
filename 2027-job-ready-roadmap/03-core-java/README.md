# ☕ Module 03: Core Java Mastery (Java 21 LTS)

## Overview
Java remains the backbone of global enterprise backend systems, financial engines, and large-scale distributed architectures. This module takes you deep into the JVM runtime, memory management, SOLID object-oriented design, Collections internals, concurrency, and Project Loom Virtual Threads.

## Learning Path & Topics
| Subtopic | Focus Areas | Difficulty | Estimated Hours | Path |
|:---|:---|:---:|:---:|:---|
| **Java Fundamentals & JVM** | JVM memory, Stack vs Heap, GC (ZGC/G1), Records, Sealed classes | Beginner | 14 hrs | [java-fundamentals/](java-fundamentals/README.md) |
| **Advanced OOP & SOLID** | SOLID principles, Polymorphism, Enterprise GoF design patterns | Intermediate | 16 hrs | [oops/](oops/README.md) |
| **Collections Framework** | HashMap internals, ConcurrentHashMap, Red-Black trees, Generics | Intermediate | 18 hrs | [collections/](collections/README.md) |
| **Multithreading & Concurrency** | Thread lifecycle, Locks, ReentrantLock, ExecutorService, Volatile | Advanced | 22 hrs | [multithreading/](multithreading/README.md) |
| **Virtual Threads (Project Loom)** | Carrier threads, Continuation yielding, High-throughput I/O | Advanced | 12 hrs | [virtual-threads/](virtual-threads/README.md) |
| **Functional Programming** | Lambdas, Functional Interfaces (Predicate, Function, Consumer) | Intermediate | 10 hrs | [functional-programming/](functional-programming/README.md) |
| **Stream API & Parallel Streams** | Map/filter/reduce, Collectors, Parallel performance pitfalls | Intermediate | 12 hrs | [streams/](streams/Streams.md) |
| **Modern File Handling (NIO.2)** | Path, Files, Channels, ByteBuffers, Asynchronous file I/O | Intermediate | 8 hrs | [file-handling/](file-handling/Virtual_threads.md) |

## Prerequisites
- Basic programming concepts (variables, conditionals, loops).
