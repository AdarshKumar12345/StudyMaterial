# ☁️ Module 05: Cloud Infrastructure & DevOps

## Overview
Learn to package, ship and run backend applications in production: containerize with Docker, deploy on AWS, orchestrate with Kubernetes, automate delivery with Jenkins CI/CD, and front everything with Nginx.

## Learning Path & Topics
| Subtopic | Focus Areas | Difficulty | Estimated Hours | Path |
|:---|:---|:---:|:---:|:---|
| **Docker & Docker Compose** | Images, containers, multi-stage builds, volumes, networks, Compose | Intermediate | 14 hrs | [docker/](docker/Docker.md) |
| **AWS Core Services** | IAM, VPC, EC2, S3, RDS, CloudWatch, SDK | Intermediate | 18 hrs | [aws/](aws/AWS.md) |
| **Kubernetes & Helm** | Pods, Deployments, Services, Ingress, ConfigMaps, Secrets, Helm | Advanced | 24 hrs | [kubernetes/](kubernetes/Kubernetes.md) |
| **Jenkins CI/CD** | Declarative pipelines, Docker agents, credentials, deployments | Intermediate | 12 hrs | [jenkins/](jenkins/Jenkins.md) |
| **Nginx** | Reverse proxy, load balancing, SSL/TLS, caching, rate limiting | Intermediate | 10 hrs | [nginx/](nginx/Nginx.md) |

## Prerequisites
- Linux command line, Git/GitHub, a working Spring Boot or Node.js app.

## Suggested Order
Docker → Nginx → AWS → Jenkins → Kubernetes
